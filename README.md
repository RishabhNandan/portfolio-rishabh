# Rishabh Nandan | Personal Developer Portfolio

[![Vercel Deployment](https://img.shields.io/badge/Vercel-Deploys-black?logo=vercel)](https://portfolio-rishabh.vercel.app/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An interactive, responsive portfolio website built for **Rishabh Nandan** – Data Science Student (BCA + MCA at University of Allahabad), Data Analyst, and Full-Stack Web Developer.

## 🚀 Key Features

- ⚡ **Interactive Terminal Graphic**: Dynamic typewriter effect featuring core skills, terminal commands, and system status.
- 🎨 **Futuristic Cyber-Dark Glassmorphism Theme**: Clean layout with glowing cyan and purple neon accents.
- 📊 **Categorized Tech Stack**: Python, Java, SQL, Scikit-learn, TensorFlow, Next.js, React, Tableau, Power BI, Prisma ORM, MySQL, MongoDB.
- 📁 **Filterable Project Grid**: Filter projects dynamically by `All`, `Full-Stack Web`, `Data Science & ML`, and `Analytics & Dashboards`.
- 🔍 **Interactive Project Modal Popups**: Click on any project card to view architecture details, feature summaries, tech tags, and links.
- 📈 **Stats Banner**: Key metrics showcasing completed projects, dataset sizes, and academic background.

## 🛠️ Featured Builds Included

1. **Shanti Neuro Clinic – Hospital & Patient Management System** (`Next.js`, `Prisma`, `PostgreSQL`, `Tailwind CSS`)
2. **Aadhaar Accessibility & Inclusion Analytics** (`React`, `Data Visualization`, `Frontend`)
3. **Predictive Analysis of Student Performance** (`Python`, `Scikit-learn`, `Machine Learning`)
4. **Sales Dashboard BI** (`Tableau`, `Data Analysis`, `SQL`)
5. **CMP ICT Admission Data Portal** (`Python`, `SQL`, `Data Automation`)
6. **Data Insights Analytics Portal** (`Power BI`, `Tableau`, `Analytics`)

## 💻 Deployment on Vercel

Simply push this repository to GitHub and connect it to Vercel:

```bash
git remote add origin https://github.com/RishabhNandan/portfolio-rishabh.git
git branch -M main
git push -u origin main
```
